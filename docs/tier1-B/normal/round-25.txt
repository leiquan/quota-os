Quota OS microkernel
三级资源声明的教学微内核。保证来自启动前的整机预分配，不来自事后抢占补救。
[boot] x0=0x44000000 physical RAM span 128 MB (probed)
[boot] DTB at 0x44000000
[boot] DTB memory 134217728 bytes
[boot] tier-1 reserved 13312 KB and 1500 us/period
[boot] CNTFRQ 62500000 Hz, cntpct 2158 -> 2715 us
[boot] timer latency calibration n=62 mean=18960 ns max=40864 ns advance_ticks=1185
[boot] tier-1 display-vsync and timer-server are reserved and armed
[boot] shell task running
[boot] timer IRQ ok, jiffies=3 now=37641 us

命令（输入数字后回车）:
  1  资源表：tier 1/2/3 的 CPU 和内存，已用和剩余
  2  启动一个 tier-2 应用（会先问 allow y/n）
  3  关闭一个 tier-2 应用（a = 全部关闭）
  4  跑一次优先级演示（尊重当前的分级开关）
  5  切换分级：ON 为三级预算服务器，OFF 为普通 1ms 轮转
  6  失范应用隔离：tier-2 死循环 + tier-3 占 CPU
  7  启动 Cluster Sim（声明超过本机容量）
  8  制造内存压力，收回弹性配额
  10 启动几十个带独立切片的 tier-2 应用
  h  帮助    q  提示如何退出 QEMU
