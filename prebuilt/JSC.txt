JSC-only kernel. Not a GUI. Not the serial drop-in.

Do not point the UTM kernel picker at this file. The default kernel is
prebuilt/quotaos.bin and is the LVGL image. The previous serial drop-in
is prebuilt/quotaos-serial.bin (93744 bytes, sha256
afed7949f5b3adc6dcb3d6c86e05356ed69fd315eca55fbeafae656f62880e05).

This image is quotaos-jsc.bin. Banner Version: 016 (641dc8c). 641dc8c is
git rev-parse --short=7 of the parent of the commit that introduced these
bytes. It evaluates two JavaScriptCore CLoop scripts. It also runs
upstream CSSParserFastPaths::parseHexColor and writes that one color
through the kernel framebuffer service. It does not lay out HTML, it does
not call GraphicsContext::fillRect, and it does not take keyboard or
mouse input into WebKit.

bytes, sha256 c10dff5acdf433d266ff8a0417465298f02fedd346564ba247eb04ea7a7328d1).

The 64 MB block at 0x44000000 is one parent reservation. Its children are
the structure heap 0x44000000-0x46000000 and the malloc arena
0x46000000-0x48000000. The parent contains the arena. The children do not
overlap each other. A guest test fills the arena, checks the structure-heap
canary, and stops at the last page. Log: docs/v016/jsc/webkit-color.raw.
